# Kitap Okuyucu

Tablet için EPUB kitap okuma uygulaması (Android).

- EPUB dosyasını seç, kitaplığa eklensin
- Her sayfa tek ekranda; parmakla sürüklenen, kıvrılan sayfa efekti
- Kitaptaki resimler ve tam sayfa kapaklar
- Kelime / cümle işaretleme (4 renk), işaretlere not ekleme, işarete dokununca notu görme
- Seçilen kelime ya da cümleyi uygulama içinde çevirme (internet gerekir)
- Sayfa numarasıyla istenen sayfayı açma, kaydırıcıyla hızlı gezinme
- Kitapta arama, yer imleri, okurken ekranın açık kalması
- İçindekiler, yazı boyutu, satır aralığı, kenar boşluğu, kâğıt / beyaz / gece teması
